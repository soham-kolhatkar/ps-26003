# Smriti

AI-based cognitive gaming and memory assistance platform for elderly dementia patients in the North Eastern Region (SIH 2026, PS 26003).

## Quick start
```bash
npm install          # uses the public npm registry via .npmrc
npm run tunnel       # scan the QR with Expo Go (SDK 57) on Android
npm run check        # typecheck + lint + tests + expo-doctor
```
